# Ernest Ngai Hei Ho — personal website

Static, responsive personal website based on `prompt.txt`.

- `index.html`: About
- `publications.html`: Publication List, with DOI links
- `skills.html`: Skills
- `photo.html`: Penghu labmates photo
- `css/`: shared and page-specific styles
- `image/`: supplied photographs

Open `index.html` directly, or preview locally:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000. No installation or build is needed.

For GitHub Pages, serve the repository root from the selected branch in the repository's Pages settings. Navigation uses relative URLs so it also works under a repository subpath.
